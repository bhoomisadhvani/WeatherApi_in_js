# 🌤️ Weather API

A simple and beginner-friendly Weather API project built using **HTML, CSS, JavaScript, Bootstrap and OpenWeather API**.

This project allows users to enter a city name and check the current weather information such as city name, temperature and weather condition.

---

## 🚀 Features

- 🌍 Search weather by city name
- 🌡️ Displays current temperature in Celsius
- ☁️ Displays current weather condition
- ❌ Shows message when city is not found
- ⚠️ Shows validation message if city name is empty
- 🔄 Uses JavaScript `async/await`
- 📡 Uses Fetch API to get weather data
- 📱 Responsive design using Bootstrap

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.8
- Fetch API
- OpenWeather API
